# Is Alex on Vacation?

This is probably a question you have asked yourself multiple times a day, but there was never a way to check, and you also didn't want to bother Alex directly to get an answer. But now this is a thing of the past, all thanks to the isAlexOnVacation?-Tracker. Now you can check all day long whether he is currently somewhere within the borders of Lower Austria or if he is having the time of his life, chasing freedom across the globe.

## Installation

First, add the domain name and API key of Alex's DAWARICH Server to the `docker-compose.yml`, and then everything should be ready. With `docker compose up`, everything should be up and running within seconds.

I hope you enjoy your stalking activities.
